# Security Policy

## Reporting a Vulnerability

If you discover a security vulnerability in this repository, **please do not open a public GitHub issue**.

Instead, report it privately via email:

- **Contact:** `jonathan07ernest@gmail.com`
- **Subject:** `[SECURITY] <repo-name> — Brief Description`

Please include steps to reproduce, affected endpoints/files, and potential impact. You can expect an acknowledgment within 48 hours.
